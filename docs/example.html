Este artigo e inteiramente ficticio. Ele demonstra o HTML exportado pelo X-HTML, sem capturas de uma conta real.

Leia mesmo sem conexao

O texto e as midias disponiveis ficam no arquivo. Os links externos continuam clicaveis quando voce escolhe abri-los.

Codigo que continua legivel

const ideia = "Guardar conhecimento";
console.log(ideia);

Espacos, indentacao e quebras de linha sao preservados. Blocos longos podem ser rolados sem esticar a pagina.

Tres formas de salvar

  • HTML unico com midias incorporadas.
  • Markdown com uma pasta relativa de midias.
  • Somente os arquivos de midia.
